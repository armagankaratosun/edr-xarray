# Ideas

Possible future work that is not yet accepted scope:

- Retry, backoff, and cache hooks for server-specific packages.
- Async transport support if xarray backend integration has a clear synchronous
  boundary.
- Support for EDR query types beyond `/cubes`.
- Broader CoverageJSON domain support beyond Grid NdArray responses.
- Optional docs site generated from Markdown and notebooks.
- Server capability probing that can recommend discovery modes or chunking.
